Vision

Bridgeflow documentation is intentionally split into two tracks:

  1. Today: the live Control Tower in production.
  2. Tomorrow: BF-INTEGRATION, the long-term enterprise runtime architecture.

Today (Live)

Current production scope: - public resilience control tower - normalized event ingest - policy-driven risk and case workflows

Start here: - ../current/control-tower/

Tomorrow (BF-INTEGRATION)

BF-INTEGRATION is the roadmap for deep enterprise integration: - adapter ecosystem (ERP/WMS/TMS) - richer orchestration and command execution - broader tenant self-service integration tooling

Curated roadmap: - ../roadmap/future-architecture/

Archived vision library (preserved, labeled as planned/in development): - ../vision/ - ../vision/bf-integration/

Why This Split Exists

This structure keeps the live system easy to adopt while preserving the original architecture vision for future phases.
