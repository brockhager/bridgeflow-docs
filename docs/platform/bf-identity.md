# Service: bf-identity

## Purpose

Authentication and authorization service (JWT issuance, user and role management, org scoping).

## API Endpoint

- Common base reference in workspace code: `https://bf-identity.up.railway.app`
- Core endpoints:
  - `POST /auth/login`
  - `GET /health`
  - `POST /users`
