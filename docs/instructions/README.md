# Project Instructions Directory

This folder is the canonical location for operational instructions and developer runbooks for the BridgeFlow project.

From now on, all instructions, runbooks, and task handoffs should be placed here.

Guidelines
- Filename: use a descriptive filename (e.g., `run-e2e-email.md`, `deploy-ci.md`).
- Format: Markdown preferred. Include environment variables and exact PowerShell commands where applicable.
- Secrets: never commit credentials. Use environment variables or local .env files excluded by `.gitignore`.
- Ownership: add an author/owner line and date on new files.
