# Breakfixes

This folder contains short, actionable breakfix notes documenting recent incident fixes, root causes, and follow-up actions.

## How to use
- Add a new markdown file for each breakfix (e.g., `YYYY-MM-DD-brief-title.md`).
- Keep each note concise: Summary, Impact, Root cause, Fix implemented, Verification, Next steps.
- Link related commits, PRs, or issues when applicable.
