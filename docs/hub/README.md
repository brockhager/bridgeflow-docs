# BridgeFlow Hub - Central Dashboard

## Purpose
Single starting point for all BridgeFlow tools, pages, and resources.

## Quick Start
1. **Open:** `docs/hub/index.html` in your browser
2. **Or start server:** `npx http-server . -p 8080`
3. **Navigate to:** `http://localhost:8080/docs/hub/`

## Sections

### 🧪 Testing Tools
- **Visual Canvas Test Helper** - Test canvas interface
- **Bridge Form Tester** - Test bridge creation forms

### 📄 Marketing & Documentation
- **Public Documentation** - User docs (Read the Docs)
- **Landing Page Preview** - Marketing homepage
- **Pricing Page** - Pricing information

### 🏢 App Interfaces
- **Visual Canvas** - Main canvas interface
- **Bridge Management** - List and manage bridges

### 📊 Admin & Utilities
- **File Location Map** - Where everything lives
- **Quick Status** - Project health check

## Testing the Visual Canvas
1. From hub, click "Visual Canvas Test Helper"
2. Click "Add Sample Bridges"
3. Click "Open Canvas"
4. Explore bridge cards and details

## Troubleshooting
- **Broken links?** Check file paths exist in repository
- **Server not starting?** Ensure you're in repo root directory
- **Missing files?** Run: `git status` to see latest commits
