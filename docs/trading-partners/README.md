# Trading Partners

This folder contains comprehensive documentation for Trading Partners (TPs) in BridgeFlow.

Files:
- `overview.md` — What a Trading Partner is and its key fields.
- `api.md` — Public and admin API endpoints related to trading partners.
- `admin-ui.md` — Notes on the admin UI pages (partner management, connection profile UI).
- `integrations.md` — Integration flows: QuickBooks (QBO), CSV mailbox, Partner inbound gateway.
- `security.md` — RLS, API key handling, encryption and access control.
- `troubleshooting.md` — Common issues, logs, and debugging tips.
- `examples.md` — Example payloads and curl snippets.

Use these docs as the single source of truth for onboarding, debugging, and implementing TP-related features.
